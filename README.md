# DragonDex

## Descripción
DragonDex es una aplicación web de consulta sobre personajes de Dragon Ball. Su propósito es mostrar información de los personajes de una manera sencilla y visual, facilitando que los seguidores de la serie exploren sus datos desde una página web.
